LIMITATIONS
- The build container does not have the user's physical cameras or target audio/video devices. Actual camera streams, MPV rendering/audio and file-manager launch require target-PC validation.
- The source package contains the runtime builder, not downloaded MediaMTX/FFmpeg executables. Existing project-local runtime binaries are preserved by the V8.0.2 in-place updater.
- Python source edits are committed immediately but the running interpreter loads them only after Restart Everything.
